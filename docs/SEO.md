# SEO и видимость в поиске / AI-ассистентах

## Что сделано в коде

| Файл | Что делает |
| --- | --- |
| `src/lib/seo.ts` | Канонический домен (`SITE_URL`), название, описание и ключевые фразы сайта. |
| `src/app/layout.tsx` | `metadataBase`, шаблон заголовков `… \| Аптека Ватан`, Open Graph, verification-теги, JSON-LD `WebSite` + `Pharmacy`. |
| `src/app/page.tsx` | Видимый H1 «Аптека Ватан — заказ лекарств с доставкой в Душанбе» и блок «Как заказать»; страницы поиска `/?q=` закрыты `noindex, follow`. |
| `src/app/medicine/[name]/page.tsx` | Заголовок `Название — купить в Душанбе, цена N сомони`, description, canonical, JSON-LD `Product`/`Offer` (цена, наличие). |
| `src/app/category/[slug]/page.tsx` | Заголовок и описание категории, canonical с учётом пагинации. |
| `src/app/sitemap.ts` | `/sitemap.xml`: главная, каталог, категории и все товары категорий; пересобирается раз в сутки. |
| `src/app/robots.ts` | `/robots.txt`: закрывает `/admin`, `/staff`, `/api/`, корзину, избранное и tracking; указывает sitemap. |
| `src/config/site-footer.ts` | Адрес, телефоны, часы работы и Instagram — используются и в подвале, и в JSON-LD `Pharmacy`. |
| `public/llms.txt` | Краткое описание аптеки и инструкции «как заказать» для AI-ассистентов. |

Товары, которые не входят ни в одну активную категорию, в sitemap не попадают; они индексируются
только по внутренним ссылкам (карусели, категории).

## Запросы, под которые оптимизирован сайт

- Бренд на русском, таджикском и латиницей: «аптека Ватан», «Дорухонаи Ватан», «Apteka Vatan»,
  «aptekavatan», «aptekavatan.tj» — в заголовке главной, видимом тексте (блок `lang="tg"`) и `alternateName`.
- Товары: «<название> купить в Душанбе», «<название> цена» — заголовок, описание и видимый блок на
  странице товара (русский + таджикский).
- Общие запросы вроде «парацетамол» без города занимают справочники (Википедия, Видаль и т. п.);
  реальная цель — «парацетамол Душанбе», «нурофен цена Душанбе».

## Переменные окружения Vercel (Production)

Задаются в Vercel → Project → Settings → Environment Variables. `SITE_URL` обязателен **до сборки**:
`robots.txt` генерируется статически.

| Переменная | Пример | Обязательна |
| --- | --- | --- |
| `SITE_URL` | `https://<ваш-домен>` | да |
| `GOOGLE_SITE_VERIFICATION` | код из Google Search Console (HTML-тег, только `content`) | для подтверждения |
| `YANDEX_VERIFICATION` | код из Яндекс Вебмастера | для подтверждения |
| `BING_SITE_VERIFICATION` | код из Bing Webmaster Tools | для подтверждения |
| `SITE_PHONE` | `+992 …` | рекомендуется |
| `SITE_STREET_ADDRESS` | улица и дом аптеки | рекомендуется |
| `SITE_SOCIAL_LINKS` | `https://instagram.com/…,https://t.me/…` (через запятую) | рекомендуется |

## Что нужно сделать вне кода (владельцу)

1. **Свой домен.** Сайт должен открываться на собственном домене (например `.tj`), а не на `*.vercel.app`.
2. **Google Search Console** — добавить домен, подтвердить (`GOOGLE_SITE_VERIFICATION`), отправить
   `https://<домен>/sitemap.xml`, запросить индексирование главной.
3. **Google Business Profile (Google Карты)** — карточка «Аптека Ватан» с адресом, телефоном, часами,
   фото и ссылкой на сайт. Это главный фактор для запросов «аптека Душанбе» и для ответов AI.
4. **Яндекс Вебмастер + Яндекс Бизнес** — то же самое для Яндекса (им активно пользуются в Таджикистане).
5. **Bing Webmaster Tools** — на Bing опираются ChatGPT Search и Copilot; импорт из Search Console в один клик.
6. **2ГИС и другие справочники** — одинаковые название, адрес, телефон везде.
7. **Ссылки на сайт** из Instagram, Telegram, Facebook, WhatsApp-статуса, местных каталогов и СМИ.
   Ссылки из соцсетей ведут на сайт — так Google понимает, что официальный ресурс бренда — сайт.
8. **Отзывы** в Google/Яндекс-картах: просить покупателей оставлять отзывы и отвечать на них.
9. **Контент.** Фото товаров и короткие описания популярных препаратов повышают позиции по запросам
   вида «Укальция Душанбе»; страница «Контакты/О нас» с адресом и картой.

Гарантировать «первое место» по любому запросу никто не может: позиции определяют Google, Яндекс и
AI-сервисы. По брендовому запросу «аптека Ватан» после индексации и карточки на картах сайт обычно
выходит первым; по товарным запросам — в течение нескольких недель после индексации sitemap.
